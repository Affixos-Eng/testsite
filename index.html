How It Works

From deployment to insights
in four steps

A complete system — from the tag on the equipment to the live dashboard in your operations centre.

1

Deploy Tags & Anchors

Attach compact UWB tags to assets. Mount weatherproof anchors at fixed positions to establish the tracking infrastructure across each floor — no new network drops or rewiring required.

2

Real-Time Signal Detection

Tags initiate DS-TWR ranging pulses. Sub-centimetre time-of-flight measurements resolve precise position data continuously at 4ms latency.

3

Analytics & AI Processing

Trilateration with Kalman filtering resolves 3D coordinates. The AI layer surfaces utilisation patterns, bottlenecks, and predictive maintenance alerts.

4

Dashboard & Integration

Live floor-plan overlays, utilisation reports, and customisable alerts via the web dashboard. REST API connects seamlessly with your existing systems.
